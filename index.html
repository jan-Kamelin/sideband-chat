How it works

Open this HTML file in a modern browser with internet access. Everyone needs a copy and a different peer ID. No installation or server hosting needed.

PeerJS loads from a CDN and uses its public signaling server. Direct chats travel over WebRTC; group messages pass through the room creator’s browser. The creator must stay online. Rooms hold up to 12 people.

Messages stay in this tab’s memory and disappear on reload. There is no offline delivery. Peer IDs are not verified identities or password-protected accounts. Room codes grant entry: share privately. WebRTC encrypts transport, but the room creator can read group messages. Some networks need a TURN relay; this app does not configure one.
